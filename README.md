# MrDork 🎯

**MR. DORK** - Advanced Google Dork Search Engine for Security Analysts

`302+ dorks` | `28 categories` | `Python` + `Bash`

---

## Features

- 📁 SQLite database for favorites, history & statistics
- 🔍 Global search across all dorks
- ⭐ Save & manage favorite dorks
- 🛠️ Create custom dorks
- 📜 Search history tracking
- ⚡ Run all dorks in a category sequentially

## Categories

PDF | Excel | Word | Database | Logs | Backups | Admin Panels | Login Pages | phpMyAdmin | cPanel | Open Directories | Passwords | API Keys | Config Files | IoT Cameras | Analytics | Git | VPN | Email | E-commerce | Healthcare | Education | Network Devices | Developer Tools

## Quick Start

```bash
git clone https://github.com/tc4dy/MrDork
cd MrDork
python dork.py
```
Bash (.sh) Version 
```bash
bash dork.sh
```
Or Lite Version (Not recommended)
```bash
bash dork_lite.sh
```

Requirements

 [+] Python 3.6+ or Bash 4.0+

 [+] SQLite3

 [+] Internet connection

 [+] Web browser
